# Worklog

This section records the weekly progress of the **Cloud-Native AI Fitness Assistant on AWS** internship project, from Week 1 to Week 12.

{{% notice note %}}
Deployment tasks are dated by when their AWS resources were created, as recorded in the deployment runbook ([Workshop 5.4](../5-Workshop/5.4-Deployment-Guide/)).
{{% /notice %}}

Each weekly log includes the objectives, a task table with dates and references, and the results (theory, hands-on work and how it applies to the project). The module weeks also record the difficulties met, how they were solved and the AWS services learned, and most weeks end with links to the related [Workshop](../5-Workshop/), blog or event pages.

### Weeks

1. [Week 1](1.1-Week1/) — AWS account, Free Tier and the first labs (IAM, VPC, EC2, RDS)
2. [Week 2](1.2-Week2/) — Report template, core service labs and a first look at the project source
3. [Week 3](1.3-Week3/) — Migration strategies (7Rs), VM and database migration, production Dockerfiles
4. [Week 4](1.4-Week4/) — Module 3 and the first deployment: network, Aurora, Auth, frontend and User
5. [Week 5](1.5-Week5/) — Modules 3–4 (serverless) and the Fitness service
6. [Week 6](1.6-Week6/) — Module 5 (containers), Gym and Payment, and the plan for Chat
7. [Week 7](1.7-Week7/) — Module 6 (data and analytics) and the AI service
8. [Week 8](1.8-Week8/) — Module 7 (AI/ML), Chat on ECS Fargate and data migration
9. [Week 9](1.9-Week9/) — Blog 2: secure multi-tenant RAG with Amazon Bedrock
10. [Week 10](1.10-Week10/) — Blog post on console access and the group project frontend
11. [Week 11](1.11-Week11/) — Group project frontend refinements
12. [Week 12](1.12-Week12/) — Worklog review and the final report
